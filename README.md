Apples game:

A simple yet challenging 2D platformer where the player navigates through a dangerous level,collecting apples and avoiding deadly holes to reach the end.

Gameplay:

Explore a level filled with tricky platforms Collect all Apples to maximize your score Avoid falling into holes Reach the end point safely

Controls:

Move Left: A or ← Move Right: D or → Jump → Space

Features:

Smooth and responsive player movement Challenging platform design Collectible items

Built With:

Godot Engine

Project Structure:

player.tscn → Player character platform.tscn → Platforms apple.tscn → Collectibles killzone.tscn → Death zones Game.tscn → Main scene
